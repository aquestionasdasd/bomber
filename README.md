# ボンバーディフューザー3Dオンライン

共同開発は [CONTRIBUTING.md](./CONTRIBUTING.md)、Codex/Claude共通ルールは [AGENTS.md](./AGENTS.md)、継続改善の一覧は [DEVELOPMENT-BACKLOG.md](./DEVELOPMENT-BACKLOG.md) を参照してください。

橋本駅前を舞台にした、ブラウザー用の3DタクティカルFPSです。対戦エリアを164m四方の駅前に絞り、2つの設置地点と3つの進入ルートを持つ競技向けの配置にしています。ライフル装備時の走行で、攻撃スポーンからサイトまで約15〜17秒、A/B間は約15秒です。

駅コンコース、北口広場、商業棟、歩行者デッキを手作りの3Dモデルで構成しています。窓枠、柱、庇、店先、案内板、手すり、舗装、植栽、遮蔽物に立体的な細部を加えています。橋本駅前を参考にしたゲーム用のアレンジで、実際の測量模型ではありません。

## 起動

Node.js 22.13以降とChrome / Edgeを使います。この作業フォルダーでは依存パッケージをインストール済みです。別のPCへコピーした場合は、先にこのフォルダーで `npm install` を実行してください。

Windowsでは `起動.cmd` をダブルクリックすると、オンライン用バックエンドを含むSites / Vinext開発サーバーを隠れたウィンドウで起動し、[http://127.0.0.1:8022/play.html](http://127.0.0.1:8022/play.html) を開きます。起動確認は最大30秒待ちます。同じゲームが起動済みなら再利用します。起動ログは `.sites-runtime/launcher.stdout.log` と `.sites-runtime/launcher.stderr.log` です。

手動で起動する場合：

```powershell
npm run dev -- --port 8022
```

ゲーム本体は `public/play.html` と同じフォルダーの各モジュール、Three.jsは `public/vendor/three.module.js` です。HTMLの直接起動では動作しません。`dist/` はSites / Vinextのビルド出力です。

### ローカルデータベースの初期化とビルド版

オンラインの部屋・参加者・通信中継はD1バインディング `DB` を使います。新しいPCなど、ローカルDBが空のときは一度だけ以下を実行してください。作成済みのDBに初期SQLを再実行する必要はありません。

```powershell
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_magical_susan_delgado.sql
npm run dev -- --port 8022
```

このコマンドは `.wrangler/state` のローカルDBへ初期スキーマを適用します。手順のオプションは[Cloudflare D1の公式コマンド説明](https://developers.cloudflare.com/d1/wrangler-commands/#d1-execute)を参照できます。公開環境のDBはSitesの公開処理で管理します。

ビルド済みバックエンドを使う場合は、`npm run build` と初回DB適用の後に `npm run start -- --port 8022` を実行し、同じ `/play.html` を開きます。

ローカルのソロ対戦・練習だけなら `node server.cjs` で [http://127.0.0.1:8018/play.html](http://127.0.0.1:8018/play.html) を開けます。この簡易サーバーで部屋APIを呼ぶと、オンライン対応の起動方法を案内します。

## 遊び方

ソロ対戦では、プレイヤーと味方ボット4体の5人チームで、敵ボット5体と対戦します。メニューで試合形式と開始サイドを選べます。

### 友達とオンライン対戦

全員が同じ公開サイトを開き、メニューのオンライン入口を使います。ローカルの `127.0.0.1` は、そのPC自身を指すため、離れた友達には公開サイトのURLを共有してください。

1. ホストが名前を入力して部屋を作り、表示された8文字の部屋番号を友達へ共有します。
2. 友達が同じサイトで名前と部屋番号を入力して参加します。
3. BLUE / REDの両チームへ人を最低1人ずつ配置し、全員が「準備完了」を押します。ホストはBLUE固定です。
4. ホストが試合形式を選んで開始します。最大10人、各チーム5人まで参加でき、空席はボットが補います。

試合進行はホストのブラウザーが管理します。ホストがタブを非表示にすると全員の試合を一時停止し、戻ると再開します。ホストの退出で部屋は終了します。ゲストが退出した席はボットへ引き継ぎます。

ゲストは同じタブを再読み込みしても、参加情報をサーバーで確認して同じ席へ自動復帰します。通信が20秒以上途切れた席は一時的にボットが操作し、接続が戻ると同じキャラクターへ操作を返します。ボットが倒されていた場合は次のラウンドで復帰します。参加情報はタブ内の `sessionStorage` に保存し、退出・部屋の終了・期限切れで削除します。別タブや別端末への引き継ぎには対応していません。

ホストが再読み込みすると進行中の世界を復元できないため、その部屋を終了し、新しい部屋を作る案内を表示します。

通信はWebRTCの直接接続を優先し、接続できない場合はHTTP中継へ切り替えます。直接接続と中継の処理は実装・ローカル検証済みですが、異なる実ネットワーク間での対戦品質はまだ未検証です。

「マップ練習」では時間制限や敵の攻撃なしで対戦マップを歩けます。Mで配置を確認し、地点ボタンから練習位置へ移動できます。BでVANDAL / PHANTOMを切り替えられ、予備弾薬は自動補充します。マップ練習だけはC/Q/E/Xも無限補充し、Eの準備・発動中の状態は保ちます。対戦と練習は同じマップを使います。

「射撃訓練」では駅コンコースの標的を60秒間で撃破します。標的は1体ずつ現れ、頭での撃破は150点、胴での撃破は100点です。命中率・ヘッドショット率・撃破数を結果画面で確認でき、自己ベストは同じブラウザーに保存します。BでVANDAL / PHANTOMを切り替えられます。標的は攻撃しません。

| 形式 | 勝利条件 | 攻守交代 |
| --- | --- | --- |
| STANDARD | 13ラウンド先取。12–12以降は2点差が必要 | 12ラウンド終了後。延長は毎ラウンド交代 |
| SWIFT | 5ラウンド先取。4–4は次の1ラウンドで決着 | 4ラウンド終了後 |

各ラウンドは購入フェーズから始まり、戦闘時間は100秒です。攻撃側はAかBにスパイクを4秒長押しで設置し、45秒後の起爆まで守ります。防衛側は設置を阻止するか、設置後のスパイクを7秒長押しで解除します。解除は3.5秒まで進めると、その位置から再開できます。設置前の時間切れは防衛側の勝利です。

相手チームの全滅でもラウンドに勝てます。ただしスパイク設置後は、攻撃側が全滅しても起爆と解除の判定が続きます。自分が倒れても試合は続き、次のラウンドで復帰します。

購入フェーズに武器とシールドを買ってください。生存時の装備は次のラウンドへ持ち越し、死亡時は購入した武器を失います。通常形式は勝利3,000、敗北1,900から連敗で増額、キル200、味方攻撃側の設置300クレジットです。所持上限は9,000で、攻守交代時は800に戻ります。STANDARD延長の各ラウンドとSWIFTの4–4決着ラウンドは、装備をリセットして5,000を支給します。SWIFTは短い試合向けの専用支給額を使います。

| 操作 | キー・ボタン |
| --- | --- |
| 移動 | W / A / S / D |
| 視点・照準 | マウスを動かす（ドラッグ不要） |
| 射撃 | 左クリック長押し |
| 狙う | 右クリック長押し |
| 静かに歩く | Shift長押し |
| しゃがむ | Ctrl長押し |
| ジャンプ | Space |
| リロード | R |
| 武器を切り替える | 1：メイン武器 / 2：サイドアーム / 3：ナイフ / 4：スパイク |
| 購入画面 | B（購入フェーズのみ） |
| 購入を終えてラウンド開始 | ソロでは購入画面の開始ボタン。オンラインは購入時間終了で同時開始 |
| スパイク設置・解除 | F長押し |
| 装備中のメイン武器・スパイクを落とす | G |
| スコアボード | Tab長押し |
| 煙幕 | C（購入した回数、上限2。4.5秒持続） |
| 上昇 | Q（購入した回数、上限1） |
| ダッシュ | Eで準備、1秒後から8秒以内にEで発動。移動キーで方向指定、2キルで再補充 |
| ナイフのアルティメット | X（7ポイントで発動、5本。ナイフで撃破すると5本へ補充） |
| マップ | M |
| 一時停止・再開 | Esc |

Codex内ブラウザーでも、ゲーム画面上でマウスを動かすだけで照準が動きます。通常のChrome / Edgeでは、ゲーム開始時にポインターを固定して視点を操作できます。

画面のボタンから難易度、音量、視点感度を設定できます。感度は初期値0.35で、Escの設定から0.05〜1.50まで調整できます。旧版で保存した感度も35％へ変換します。歩行によるカメラの上下揺れはなく、銃だけが歩行に合わせて揺れます。タッチ画面向けの移動・射撃ボタンもあります。

Cの煙幕は200、Qの上昇は150クレジットで購入できます。未使用の購入スキルと獲得ポイントは通常ラウンドで持ち越し、ダッシュの準備状態と使用中のアルティメットはラウンド終了で解除します。攻守交代・延長の装備リセット時はスキルとポイントもリセットします。煙幕はボットの視界も遮り、ダッシュは地形との衝突を受けます。

## この作品について

VALORANTの標準・Swiftplayのスパイク戦を参考にした、非公式のファンメイド試作品です。Riot Gamesによる公式作品ではありません。人物・武器は、この作品用の立体モデルです。胴体・関節・防具・グローブ、銃の機構やサイトを作り込み、照準とリロードでも同じ装備を使います。

武器はCLASSIC、GHOST、SPECTRE、VANDAL、PHANTOMとナイフ、スキルはデュエリストを参考にした独自調整です。エージェント選択や延長時の引き分け投票は省略しています。

旧市街地版の参考データを保存しています。地理データ：© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)、ODbL 1.0。`public/city-data.json`、`public/data-license.txt` と `prepare-city.cjs` は資料用で、現在の手作り対戦マップからは読み込みません。

建物・駅・工事の資料：[ミウィ橋本 アクセス案内](https://www.mewe.jp/guide/access.jsp)、[アリオ橋本 アクセス](https://hashimoto.ario.jp/information/access/)、[相模原市 リニア駅工事の説明](https://www.city.sagamihara.kanagawa.jp/shisei/1026709/mayor/1009760/1032917/1034060.html)、[JR東海 神奈川県駅計画図](https://company.jr-central.co.jp/chuoshinkansen/efforts/kanagawa/_img/location_map.png)、[相模原市 2026年の工事現場写真](https://www.city.sagamihara.kanagawa.jp/_res/projects/default_project/_page_/001/036/204/01.jpg)。

ルール参考：[Riot初心者ガイド](https://playvalorant.com/en-us/news/announcements/beginners-guide/)、[Swiftplay仕様・パッチ5.12](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-5-12/)、[延長戦仕様・パッチ1.03](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-1-03/)。

## 確認

`npm run check` でルール・能力・オンライン部屋・ゲーム本体の確認をまとめて実行できます。個別には `node tests-rules.cjs`、`node tests-abilities.cjs`、`node tests-online.cjs`、`node tests.cjs` を使います。

勝敗・延長・経済・スパイク操作・シールド処理、購入スキルと補充、部屋の参加・準備・中継、出現位置・移動経路・衝突、照準・ラウンド進行・リロード・再プレイを確認します。実際の回線をまたぐ接続や体感遅延の確認は別途必要です。


ラウンド勝利BGMは Esc →「ラウンド勝利BGMを設定」で変更できます。後から共通音源を追加する開発手順は [VICTORY-MUSIC.md](VICTORY-MUSIC.md)。現在は音源未同梱です。
